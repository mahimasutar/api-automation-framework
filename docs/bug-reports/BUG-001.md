# BUG-001: POST /booking returns 500 Internal Server Error when required fields are missing

- **ID**: BUG-001
- **Title**: POST /booking unhandled 500 server crash on missing payload properties instead of 400 Bad Request
- **Severity**: High
- **Priority**: Medium
- **Environment**: Restful-Booker public instance (`https://restful-booker.herokuapp.com`), Automated test run (`VAL-001` - `VAL-004`)

## Steps to Reproduce
1. Send HTTP `POST` request to `https://restful-booker.herokuapp.com/booking`
2. Set headers:
   - `Accept: application/json`
   - `Content-Type: application/json`
3. Provide JSON body missing mandatory fields (e.g. omitted `firstname` or `bookingdates`):
   ```json
   {
     "lastname": "Smith",
     "totalprice": 100,
     "depositpaid": true,
     "additionalneeds": "Breakfast"
   }
   ```

## Expected Result (per docs)
The API documentation specifies valid JSON structure required. Client-side omission should return `400 Bad Request` with an explanatory error payload.

## Actual Result
The API crashes with HTTP `500 Internal Server Error` and plain text body:
```text
Internal Server Error
```

## Evidence
- Automated test: `tests/validation/test_booking_validation.py::test_create_booking_missing_firstname`
- Response status: `500 Internal Server Error`
- Allure report tag: `@pytest.mark.xfail(reason="BUG-001")`
