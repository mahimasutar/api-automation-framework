# BUG-002: POST /booking allows checkout date earlier than checkin date

- **ID**: BUG-002
- **Title**: POST /booking creates valid booking with checkout date before checkin date (inverted chronology)
- **Severity**: Medium
- **Priority**: Medium
- **Environment**: Restful-Booker public instance (`https://restful-booker.herokuapp.com`), Automated test run (`VAL-009`)

## Steps to Reproduce
1. Send HTTP `POST` request to `https://restful-booker.herokuapp.com/booking`
2. Provide JSON payload with checkout date before checkin date:
   ```json
   {
     "firstname": "John",
     "lastname": "Doe",
     "totalprice": 150,
     "depositpaid": true,
     "bookingdates": {
       "checkin": "2026-12-10",
       "checkout": "2026-12-01"
     },
     "additionalneeds": "None"
   }
   ```

## Expected Result
Booking system business logic should reject nonsensical date bounds where checkout precedes checkin (`checkout < checkin`) and return `400 Bad Request` or `422 Unprocessable Entity`.

## Actual Result
The API returns `200 OK` and stores the corrupted booking dates:
```json
{
  "bookingid": 3542,
  "booking": {
    "firstname": "John",
    "lastname": "Doe",
    "totalprice": 150,
    "depositpaid": true,
    "bookingdates": {
      "checkin": "2026-12-10",
      "checkout": "2026-12-01"
    },
    "additionalneeds": "None"
  }
}
```

## Evidence
- Automated test: `tests/validation/test_booking_validation.py::test_create_booking_checkout_before_checkin`
- Stored response verified via read-back persistence round-trip.
