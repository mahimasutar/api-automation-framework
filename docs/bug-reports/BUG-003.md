# BUG-003: DELETE /booking/:id returns 201 Created instead of 200/204

- **ID**: BUG-003
- **Title**: DELETE /booking/:id returns HTTP 201 Created on successful deletion
- **Severity**: Low
- **Priority**: Low
- **Environment**: Restful-Booker public instance (`https://restful-booker.herokuapp.com`), Automated test run (`CRUD-005`)

## Steps to Reproduce
1. Create a booking via `POST /booking` and acquire `bookingid`.
2. Authenticate and obtain auth token via `POST /auth`.
3. Send HTTP `DELETE` request to `https://restful-booker.herokuapp.com/booking/:id` with cookie `token=:token`.

## Expected Result (per HTTP standards)
Successful resource deletion should return `200 OK` (with confirmation body) or `204 No Content` (empty body).

## Actual Result
The API returns `201 Created` with text body:
```text
Created
```
HTTP status 201 signifies new resource creation, which directly contradicts deletion semantics.

## Evidence
- Automated test: `tests/crud/test_booking_crud.py::test_delete_booking_lifecycle`
- Response: Status `201 Created`
